# 目标输入与差异矩阵

| 输入 | 从哪里核对 | 用于判断 |
| --- | --- | --- |
| project_root / board | 实际仓库与板型配置 | 路径、构建入口和设备身份 |
| 芯片/PCB/BOM | 原理图、料号、板卡资料 | 同芯片不同板的外设/引脚/电源差别 |
| CP/AP与CPU映射 | Kconfig、启动与链接脚本 | 系统实例、逻辑/物理CPU、共享区 |
| 存储布局 | 分区文件、Flash/PSRAM/SD资料 | 边界、校准、用户区和回退 |
| SDK/ABI/工具链 | 依赖锁、头文件、manifest | 可调用接口与二进制兼容 |
| 设备注册与I/O | board bring-up与生成配置 | 接口是否实际进入当前构建 |
| 当前验证 | 对应版本的日志/结果 | 区分实现、构建、离线与设备行为 |

同芯片换板先列器件/连线/供电/存储/时序差异，再判断哪些驱动可复用、哪些仅更换board绑定。输入不足时输出明确缺口，不自动把开发板宣传参数当作事实。
