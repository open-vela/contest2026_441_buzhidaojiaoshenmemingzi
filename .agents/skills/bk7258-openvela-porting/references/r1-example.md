# R1案例：从问题到可复用检查

本页是BK7258 R1的已用案例，不是其他板的参数表。

| 案例 | 问题与处理 | 其他使用者应复用的检查 |
| --- | --- | --- |
| Audio关闭 | 固定upper-half在锁内调用shutdown；应用先明确停止和释放，再close | 查实际版本与上下文，不只复制同名回调 |
| SD-NAND退出 | 无ONCHIP_DATAFS时需要只读QUIESCE事务屏障 | 查目标板存储拓扑和guard语义，不默认DATA域存在 |
| 连续观察 | 新frame归还、音频消费与会话请求独立，取消后拒绝旧结果 | 查owner、队列、deadline、generation与重入 |
| 固件交付 | 精确基线/dirty输入和成对配置，隔离目录核查包身份 | 哈希/构建/硬件分别报告，不推定二进制或设备等价 |

脚本的既有检查与案例记录属于其具体版本；修改Skill文案不自动升级过去的脚本或硬件验证。新使用者以自己的目标、输入和结果形成新记录。
