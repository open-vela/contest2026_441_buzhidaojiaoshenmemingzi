# 文档入口

比赛终版只以以下文档为当前事实来源：

1. [系统架构](系统架构.md)：CPU0/AP/CPU2、内存、RPTUN、bring-up 和数据链总图；
2. [当前进度](progress/当前进度.md)：哪些已实机、哪些只完成源码、下一道门禁；
3. [构建与提交指南](构建与提交指南.md)：终版构建、配置核验、烧录和提交检查；
4. [参考 BSP 审查](BK7258参考BSP审查.md)：公开代码来源、可复用范围和限制；
5. [源码来源与复用边界](../SOURCE_PROVENANCE.md)：固定提交、许可证和本队修改。

`docs/progress/` 中带 2026-08 日期的文件是历史实验原始记录，保留用于追溯，
不代表当前终版状态。早期的产品规划、MVP、视觉胸牌和混合固件文档也只作为
过程资料；若与上述五个入口冲突，以上述五个入口和最新实机证据为准。

技术报告正文位于 `submission/技术报告正文草案.md`，官方格式候选稿位于
`submission/技术报告-终版候选.docx`。报告中的未测项目必须保持“未测”，不得
用参考仓、芯片手册或单次实验推导成终版性能。
