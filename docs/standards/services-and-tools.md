# 服务端与工具规范

- S01：模块导入不连接设备、不启动服务、不发起模型请求或烧录；副作用只在明确入口启用。
- S02：配置定义类型、范围、默认行为及必要字段，失败时明确报错；真实凭据从独立配置读取。
- S03：模型/后端显式选择，MiMo主后端与GLM辅助后端不隐式互相回退；超时/限额不自动增加调用。
- S04：请求体、JPEG、音频帧、结果文本及并发worker均设上限；检查内容类型、传输长度与完整性。
- S05：鉴权使用适当比较方式，工具回调只处理允许的路径，不扩展成通用代理或任意文件接口。
- S06：请求ID、租约与generation关联正确，过期、重复、取消、上传忙和无有效会话分开返回。
- S07：HTTP/SSE边界保留完整消息语义，断连/半包/部分发送/异常状态有可恢复行为。
- S08：使用连接超时和剩余deadline，读取分块与模型处理不得把已有请求无限延长。
- S09：查进程、标记READY、监听端口和公网可达是不同检查；关键回调需检查实际协议状态。
- S10：日志只记录阶段、状态、大小、耗时和必要关联信息；不输出密钥、模型完整提示、私人转写和原始媒体。
- S11：外部内容作为数据处理，照片标牌或模型结果不能改变本地权限、配置或执行工具。
- S12：Python函数与变量用snake_case、类用CapWords、四空格缩进；避免一行多语句及吞异常。
- S13：文件/socket/锁用上下文管理或finally释放，异常限定到可处理范围；不能把未知异常当有效空结果。
- S14：子进程使用参数数组，检查退出码；禁止插值拼接不可信shell文本。
- S15：PowerShell约束参数、处理错误并在finally清理；后台进程身份明确，不能按宽泛名称杀其他应用。
- S16：安装、恢复和导出工具默认预检，拒绝路径逃逸/覆盖/符号链接异常；生成物写到明确目录。
- S17：候选生成和发布分开；工具不能代签人工批准或把暂存目录直接当作正式发布。
- S18：清理与停止幂等，保留失败记录，不以删日志或更换模型掩盖结果。
