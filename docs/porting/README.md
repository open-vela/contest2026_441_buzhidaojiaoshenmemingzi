## 读表方式

- **已有基础**：内核/协议/SDK及公开BSP等底座，保留真实组件声明。
- **移植适配**：固定OS版本、板级拓扑、设备合同与产品配置的具体接入。
- **本项目功能**：可关联具体差分的交互、资源管理、恢复与验证工作。

CP/AP启动和SMP是交付能力的一部分；产品贡献重点落到R1成对配置、标准媒体合同、存储退出、三键交互、同场连续观察与可复现交付。LCD/LVGL位于驱动与组件适配范围，不列作视障用户的产品功能。
