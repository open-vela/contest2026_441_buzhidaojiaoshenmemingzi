# 芯片接口定义

目录：`chips/bk7258/include/`。按核心职责划分为**4组**；目录内源/配置文件95项。

| 职责 | 关键入口 | 已有基础 | 本项目适配/功能工作 |
| --- | --- | --- | --- |
| 处理器与共享内存 | bk7258_amp.h、bk7258_ap_lifecycle.h | 平台ABI定义 | 配合CP/AP配置核对内存和角色 |
| 设备子系统接口 | bk7258_aud.h、bk7258_dvp.h等 | 已有驱动声明 | 随具体驱动适配维护合同 |
| 资源、电源与存储接口 | bk7258_storage_guard.h、bk7258_pm.h | 已有类型及约束 | 同步QUIESCE等新增用途的声明和边界 |
| 镜像与SDK契约 | bk7258_image_layout.h、bk7258_mcuboot_format.h | 固定布局/格式基础 | 用于构建与交付一致性检查 |
